# Changelog

## 0.1.0 - 2026-07-16

- Initial public release.
- Configurable local inbox, archive root, and classification rules.
- SwiftBar menu and Claude Code skill integration.
- Stable-file watcher running in a terminal-owned tmux session.
- Constrained move primitive with path boundaries, no-overwrite behavior,
  duplicate detection, JSONL ledger, and dry-run-first undo.
- Sanitized defaults with no personal paths, filing rules, logs, or secrets.
